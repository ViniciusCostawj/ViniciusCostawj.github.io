A.L.A.N. v2.0 - Sistema Multi-Agente Autônomo

Auditoria Forense com Self-Correction e RAG Multimodal

Uma força de trabalho digital composta por **três agentes especializados** orquestrados via **LangGraph**, projetada para automatizar análises forenses complexas no setor financeiro (SPB/Pix). Supera RAGs tradicionais com capacidade de raciocínio e validação.

Diferenciais Técnicos:
✅ Orquestração Multi-Agente: Fluxo de estado gerenciado entre agentes Pesquisador, Redator e Crítico.
🔄 Self-Correction Loop: O agente Crítico avalia tecnicamente a resposta e **rejeita/refaz** o processo autonomamente se encontrar erros.
🧠 RAG Avançado (Qdrant): Ingestão multimodal (PDFs, CSVs complexos, XSDs legados) para memória vetorial de alta precisão.
🐳 Infraestrutura: 100% conteinerizado em Docker, com Llama 3 local para privacidade e API via FastAPI.
